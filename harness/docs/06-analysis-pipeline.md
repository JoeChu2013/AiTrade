## ★ 12 排除规则落位：粗排 + 精排（精排并入阶段4）
排除规则不是独立阶段，而是跑两次：
- **粗排（深析前）**：漏斗 WF7 用廉价指标筛掉明显废标，省 LLM。
- **精排（阶段4 风控第一层）**：用阶段1-3 采集出的丰富数据跑**全 12 条**（尤其定性项 E-04/06/10/12），**计数分级**：0-1 合格、≥2 → 只可观察、安全红线单条即剔除。

## 阶段 0 · 环境分析　【harness】
- **角色**：① 市场宏观分析师。
- **动作**：定级 **S/A/B/C/D**，确定基础操作基调（总仓位区间/单票上限/开仓额度）。
- **闸**：D 级 → 直接终止 WF1（强制空仓）。
- **输出**：`regime`。注入后续每阶段（P-07 禁止省略环境注入）。

## 阶段 1 · 四大分析师同步采集　【开源】
- **角色**：② 基本面 / ③ 新闻政策 / ④ 情绪资金 ＋ 深析内置技术，**并行**（Fork-B=B1）。
- **输出**：`fundamentals_report` / `news_report` / `sentiment_report` / `market_report`。
- **红线**：P-08 不得仅抛原始数据——每份须含结论段+数值依据。

## 阶段 2 · 多空辩论 + 主管裁决 + 研报　【开源】
> 旧阶段2(辩论)+旧阶段3(研报) 合并。
- **角色**：⑤ 多头 ⇄ 强制辩论 ⇄ ⑥ 空头 → ⑦ 研究主管裁决 → 标准化研报。
- **机制**：`max_debate_rounds` 轮双向推演；主管整合双方裁决。
- **输出**：`investment_debate_state` + `investment_plan`（研报）。
- **红线**：P-09 禁止单向论证（多空缺一即作废重算）；P-03 禁止主观臆测填充。

## 阶段 3 · 交易员 R:R + 买点精算　【harness + 开源】
- **角色**：⑩ 交易测算员。
- **动作**：算 **盈亏比 R:R**＝(止盈位−买点)/(买点−止损位)、**买点**（入场价区间）、**建议仓位**（按环境封顶）。
- **门槛**：R:R < 2 → 影响最终评级（降级，见决策表）；R:R 决定能否进入"可买"档。
- **输出**：`trader_investment_plan` + 候选 `HarnessDecision{买点, R:R, 仓位, 止盈, 止损}`。

## 阶段 4 · 三层风控 + 主管终裁　【harness】
> "三层风控"的实现见 Fork-A。本文按推荐解释（三道确定性风控层）：

| 层 | 内容 | 角色/机制 |
|---|---|---|
| **L1 排除精排** | 12 条计数分级（含红线） | ⑧ 选股筛选 |
| **L2 纪律风控** | 持仓数/单票/总仓位/浮亏/止损三档/买入条件闸/时间闸 | ⑫ 一级风控 + `vet_trade` |
| **L3 环境风控** | D/C 级复核、政策利空一票压级 | 环境闸 |
| **终裁** | 一票否决（任一层不过 → 否决/降级） | ⑬ 终审主管 |

- **红线**：P-02 不得跳过低级风控；P-11 不得忽略仓位上限；P-12 止损不得延期；P-14 不得改风控参数。

## 阶段 5 · 报告组装 + 存档　【harness·新增】
- **角色**：L0 协调器。
- **动作**：汇总 0-4 阶段产出 → 标准研报 + **决策卡**（含 5 选 1 评级、护栏明细、数据来源 provenance、时间戳）→ **落库审计**。
- **红线**：P-13 数据须可溯源（存档即留痕）；支撑事后复盘与"作废重算"追责。

## 最终结论：5 选 1 评级（阶段5 输出）

| 评级 | 触发条件（需同时满足/对应情形） |
|---|---|
| **1 可适仓买入** | 红线0 ∧ 排除命中=0 ∧ R:R≥2 ∧ 环境≥B且有开仓额度 ∧ 持仓<3 ∧ 处买入窗口 ∧ 终审通过 ∧ 多头占优 |
| **2 条件满足才可买** | 标的本身合格（排除≤1、R:R≥2、终审通过），但**时点条件未满足**（不在买入窗口/额度暂满/价未到买点）→ 待条件 |
| **3 可买但不优先** | 合格（排除≤1）但**性价比靠后**：被取舍挤出 capacity，或 R:R 在 1.5~2 之间 |
| **4 只可观察不可买** | 排除命中 **≥2**（计数分级）∨ 环境 C 级 ∨ 关键信息缺口 ∨ 多空胶着难分 |
| **5 明确不买** | 安全红线命中 ∨ 环境 D 级 ∨ R:R<1 ∨ 空头逻辑明确占优 ∨ 终审否决 |

> 代码：新增 `BuyRating` 枚举（5 值）承载本结论，区别于执行动作 `Verdict`（买/卖/持/减/清）。映射：仅"可适仓买入"→ 可直接转 BUY；其余不立即开仓。
