# 详细设计 04 · 12 项检查/排除规则 · v2

> 你的新 12 项把"标的硬排除 + 交易纪律 + 环境 + 买入条件"合到了一起。本版逐条比对旧版，
> 相同合并、不同按新规则。并按性质分两类，喂给个股 5 选 1 评级（doc06）。

## A. 新 12 vs 旧 12 比对

| 新规则 | 旧对应 | 处理 |
|---|---|---|
| 1 基本面恶化（净利连降/毛利<20%） | 旧E-10业绩变脸 + 部分E-03现金流 | **修改合并**：换指标为净利连降+毛利率 |
| 2 估值过高（PE>行业均值2倍无增长） | 旧E-05估值泡沫（×3/95分位） | **修改**：阈值→×2 且加"无增长" |
| 3 技术面破位（破60线/MACD死叉） | 无（技术原在深析内） | **全新** |
| 4 重大利空（立案/巨额解禁/ST） | 旧E-01解禁+E-02 ST+E-04立案 | **合并三条为一红线** |
| 5 流动性不足（成交<5000万/换手<0.3%） | 旧E-07（换手<0.5%） | **修改**：换手→<0.3% |
| 6 违背市场方向（个股与大盘反） | 无 | **全新**（情境闸） |
| 7 风报比倒挂（R:R<2:1） | 旧在买入条件 doc08 | **纳入**为检查项 |
| 8 交易时机不当（14:30后/尾盘） | 旧时段闸 doc08 + D-06 | **纳入**（时段闸） |
| 9 资金管理违规（持仓>30%/超3支） | 旧D-02/D-03 纪律 | **纳入**（纪律，单票30%见Fork-B） |
| 10 除权除息干扰（前5%后3天） | 无 | **全新**（需澄清） |
| 11 系统风险（D禁/C减） | 旧环境定级 doc03 | **纳入**（环境闸） |
| 12 逻辑一致性（同板块≤2支） | 无 | **全新**（组合约束） |

**旧版被删除项**：行业政策收紧、突发商誉减值、高质押爆仓、微市值易操纵、突发事故舆情。
→ 按"新规则走"它们默认删除。但**高质押爆仓、突发事故舆情**是经典暴雷源，建议保留（见 Fork-C）。

## B. 重铸 12 条（阈值 + 分类）

分类：**【红线】**单条即剔除｜**【硬排除】**计入计数分级（0-1可买/≥2只可观察）｜**【情境闸】**不剔除标的、仅挡当下买入/影响评级。

| 规则 | 阈值 | 类型 | 绑定/数据 |
|---|---|---|---|
| **E-01 基本面恶化** | 净利润连续 ≥2 期同比下降 **或** 毛利率 <20% | 硬排除 | ②基本面；`yoy_net_profit_q`,`gross_margin` |
| **E-02 估值过高** | PE > 行业均值 **×2** 且 净利同比增长 ≤0（无增长） | 硬排除 | `pe_ttm`,`industry_pe_mean`,`yoy_net_profit` |
| **E-03 技术面破位** | 收盘 < **MA60** 且 **MACD 死叉** | 硬排除 | 深析技术；`close`,`ma60`,`macd_*` |
| **E-04 重大利空** | 立案调查 **或** ST/*ST **或** 巨额解禁（解禁/流通 >5%） **或** 高质押（第一大股东质押 >70%，C1并入） **或** 突发重大安全事故 | **红线** | ③新闻；`regulatory_event`,`is_st`,`unlock_ratio`,`top_holder_pledge_ratio`,`major_incident` |
| **E-05 流动性不足** | 近20日 日均成交额 <5000万 **或** 日均换手 <0.3% | 硬排除 | `avg_amount_20d`,`avg_turnover_20d` |
| **E-06 违背市场方向** | 个股 20 日趋势方向 与 大盘 regime 方向**相反** | 情境闸 | ①regime + 个股趋势 |
| **E-07 风报比倒挂** | R:R = 上行/下行 **<2:1** | 情境闸 | ⑩阶段3 测算 |
| **E-08 交易时机不当** | 当前 >14:30 **或** 尾盘 **或** 追涨形态（D-06） | 情境闸 | 时段闸 + D-06 |
| **E-09 资金管理违规** | 单票仓位 >30%（见Fork-B） **或** 持仓数 >3 | 纪律闸 | D-02/D-03 |
| **E-10 除权除息干扰** | ①**抢权过热**：股权登记日前（公告→登记日抢权窗口）累计涨幅 >5% → 排除；②**除权冷却**：除权除息日当天 + 后 3 个完整交易日（共 4 日）一律不建仓 | 情境闸 | `record_date`,`ex_date`,`pre_record_gain_pct`,`days_since_ex` |
| **E-11 系统风险警戒** | 大盘 **D 级禁交易** / **C 级仅减仓** | 环境闸 | doc03 regime |
| **E-12 逻辑一致性** | 同一板块持仓 **>2 支** | 组合约束 | 组合行业分布 |
| **E-13 负面舆情过热**（C1新增） | 负面舆情评分 **>80/100**（非重大事故级；重大事故归 E-04 红线） | 硬排除 | ③④；`negative_news_score` |

**两类如何喂 5 选 1 评级**（已确认 Fork-A=A1：只对硬排除/红线计数）：
- **红线**（E-04）：单条即剔除 → 明确不买。
- **硬排除·计数**（E-01/02/03/05/13）：命中 ≥2 → 只可观察。
- **情境/纪律/环境**（E-06~E-12）：不剔除标的、不计入分级，但命中即压低评级 → "条件满足才可买/可买不优先/明确不买"（如 E-11 D级→明确不买；E-08 时机→条件满足才可买；E-07 R:R<2→不优先或不买）。

## C. 缺失数据策略（沿用）
红线（E-04 的 ST/立案）可硬确认字段缺失 → 保守剔除；其余硬排除缺失 → 记 `info_gaps` 不武断剔除；情境闸缺失 → 见 doc04-Fork1=A（记缺口放行）。

## 已确认决策
- **Fork-A=A1**：只对硬排除/红线计数（红线 E-04 单条即剔；硬排除 E-01/02/03/05/13 命中≥2→只可观察）；情境/纪律/环境类不计入分级。
- **Fork-B=B1**：单票上限 = **min(环境分级档, 30%)**——环境分级为主，30% 为任何环境下的绝对兜底。
- **Fork-C=C1**：高质押（第一大股东>70%）并入 E-04 红线；负面舆情过热新增 E-13 硬排除；重大安全事故归 E-04 红线。
- **E-10 口径**：①抢权过热——股权登记日前抢权窗口累计涨幅 >5% → 排除；②除权冷却——除权除息日当天+后 3 个完整交易日不建仓。
