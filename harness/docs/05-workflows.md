# 详细设计 05 · 七套标准战术工作流

> 定位：**标准化工具库**。核心不是预测涨跌，而是用固定流程约束交易行为，克服贪婪/侥幸/情绪化。
> 协调器(L0) 根据需求自动调用、可自由组合。代码雏形在 `harness/workflows.py`。
> 标记：**【已建】**/**【强化】**/**【新增】**。

## 0. 七套是一条漏斗，组合即流程

```
WF5 市场快照(定环境) ──D级→ 停（仅 WF4 巡检存量）
        │ 非D
        ▼
WF7 批量快速筛选(上百→几十, 纯排除) ──► WF2 池内优选(几十→3-5 最优)
        │（或 WF3 横向对比，针对指定同行业小集合）
        ▼
WF1 全链路深析(对入围标的逐只深挖→研报+决策) ──► 落地（执行员⑪）
        ▼
每日收盘 ──► WF4 持仓巡检（风险等级/减清仓）   ；盘中突发 ──► WF6 补充批注（触发重评）
```

**自动调用（意图→工作流）**：协调器用轻量意图识别把请求路由到工作流——
"分析下茅台"→WF1｜"今天买啥"→WF5+WF7+WF2(+WF1)｜"对比这几只"→WF3｜"看我的持仓"→WF4｜"大盘怎样"→WF5｜"出公告了"→WF6。
意图识别由 LLM 解析、**映射到确定性工作流**（与宏观分析师同模式：LLM 解析、确定性执行）。

## WF1 · 全链路深度分析
- **用途**：重点标的深度挖掘。完整走 采集→多空调研→研报→风险排查。
- **触发**：用户指定标的；或 WF2/WF3 产出的入围名单。
- **角色**：① 提供环境上下文 → ②③④＋深析内置技术 并行采集 → ⑤⑥ 强制辩论 → ⑦ 研报 → ⑩ 测算 → ⑫⑬ 风控。
- **护栏**：前置确认未触排除；原则三/五/六；`vet_trade` 综合校验；⑬ 终审否决。
- **输出**：每标的 标准研报 + `HarnessDecision`（明确 verdict + 仓位 + 止盈止损）。
- **成本**：重（多轮 LLM）。
- **代码**：深析引擎已接（`deep_dive` adapter）。**【强化】**需把现有 `orchestrator.full_analysis`（含池筛的 composite）**拆出纯深析版** `deep_analysis(codes,...)`（见 Fork-A）。

## WF2 · 股票池内优选
- **用途**：两层池横向对比，选当下性价比最高个股。
- **触发**：日常选股、环境 ≥ B。
- **角色**：⑨ 池管理 → ⑧ 排除筛选 → 预打分优选。
- **护栏**：12 排除规则、`analyze_only_from_pool`。
- **输出**：白名单内排序后的 shortlist（**不深析**，省 LLM）。
- **成本**：轻。
- **代码**：**【已建】** `workflows.pool_optimize`。**【强化】**优选打分纳入更多性价比因子（估值分位、盈亏比预估）。

## WF3 · 多股横向对比
- **用途**：3-5 只同行业个股并排比，分优劣选最优。
- **触发**：同行业择优。
- **角色**：对每只深析（或轻析）→ ⑦ 口径统一对比。
- **护栏**：排除规则前置；对比维度固定（估值/成长/资金/风险）。
- **输出**：对比表 + 最优标的（可直接转 WF1 深挖）。
- **成本**：中（3-5 次深析）。
- **代码**：**【已建】** `workflows.compare`。**【强化】**输出结构化对比维度而非仅信号。

## WF4 · 持仓每日巡检
- **用途**：每日收盘检查全部持仓，更新风险等级，判断减/清仓。
- **触发**：**每日收盘自动**（定时任务）。
- **角色**：⑫ 一级风控（止损三档）逐仓 + ⑬ 终审（环境恶化一票否决）。
- **护栏**：D-01 止损三档；环境闸（D 级 → 清仓优先）。
- **输出**：每仓 风险等级 + 动作（减/清/持）。硬止损执行见 Fork-B。
- **成本**：轻（确定性为主）。
- **代码**：**【已建】** `workflows.portfolio_review`。**【强化】**加"风险等级"字段 + 收盘定时触发 + 单票止损线判定。

## WF5 · 大盘市场快照
- **用途**：一键当日宏观复盘——行情、资金、板块热点。
- **触发**：每日盘前/盘后（定时）；或用户问"大盘怎样"。
- **角色**：① 宏观分析师 → regime 定级 + 记录板块热点/资金流。
- **护栏**：政策利空一票压 D；缺因子记缺口。
- **输出**：`MarketRegime` + 复盘记录（**落库**，供巡检与选股复用）。
- **成本**：轻-中。
- **代码**：**【已建】** `workflows.market_snapshot`（仅定级）。**【强化】**补板块热点/资金记录 + 持久化。

## WF6 · 标的补充批注
- **用途**：对已有个股补充最新公告/突发，更新逻辑。
- **触发**：突发公告/消息（事件驱动）。
- **角色**：③ 新闻解析 → 更新逻辑 → **触发相关排除复评**（E-04/E-08/E-10/E-12）。
- **护栏**：若批注命中排除规则 → 标的转入黑名单/提示清仓。
- **输出**：批注记录 + 是否触发重评/降级。
- **成本**：轻。
- **代码**：**【已建】** `workflows.annotate`（基础）。**【强化】**加"批注→重评"钩子。

## WF7 · 批量快速筛选
- **用途**：快速过滤上百只，淘汰不合格，缩小研究范围。
- **触发**：选股第一道粗筛。
- **角色**：⑧ 选股筛选（仅 12 排除规则）。
- **护栏**：12 排除规则（纯确定性）。
- **输出**：白/黑名单（含排除原因）。
- **成本**：极轻（无 LLM）。
- **代码**：**【已建】** `workflows.batch_screen`。
