# 详细设计 08 · 分时时间规则 + 买入条件闸

> 时间硬约束作用在 ⑪ 执行员 / ⑩ 测算。总则：**14:30 后不开新仓，尾盘只卖不买。**
> 标记：**【已建】**`guardrails/time_rules.py`（需按本表重写时段）｜**【新增】**。

## A. 七大交易时段（确定性闸）

| # | 时段 | 区间 | 可交易 | 可买入 | 说明 |
|---|---|---|---|---|---|
| 1 | 集合竞价 | 09:15-09:25 | ✗ | ✗ | 只看不买，观察隔夜情绪 |
| 2 | 开盘确认 | 09:25-09:30 | ✗ | ✗ | 确认高开/低开，修正预期 |
| 3 | 早盘 | 09:30-10:00 | 谨慎 | 见 Fork-B | 主力窗口，量比 >1.5 纳入关注 |
| 4 | 上午中段 | 10:00-11:30 | ✓ | ✓ | 正常交易，**次优买入区间** |
| 5 | 午间 | 11:30-13:00 | ✗ | ✗ | 复盘上午，不决策不交易 |
| 6 | 下午 | 13:00-14:30 | ✓ | ✓ | **最后买入窗口** |
| 7 | 尾盘 | 14:30-15:00 | ✓(只卖) | ✗ | **不开新仓，只做卖出** |

- **量比 >1.5** 是早盘的"关注信号"，不是硬闸（影响是否纳入观察，不强制买卖）。
- 非交易时段（11:30-13:00、9:15-9:30、15:00 后）**禁止任何下单**；硬止损卖出顺延至最近可交易时段。
- 对应规则号：尾盘禁开新仓 = T-01；集合竞价/午间禁交易 = T-02/T-05；非交易时段 = T-04。

## B. 买入条件闸（全部满足才可开新仓）

```
可买入 = 环境等级 ≥ B
       ∧ 硬排除命中 = 0 条        ← 见 Fork-A（你写"≤1条"与硬排除冲突）
       ∧ 盈亏比 R:R ≥ 2:1
       ∧ 当前时间 < 14:30 且处于买入窗口(时段4或6；时段3见Fork-B)
       ∧ 当前持仓 < 3 支
```

逐项映射：
| 条件 | 阈值 | 绑定 |
|---|---|---|
| 环境 ≥ B | S/A/B 可开新仓；C/D = 0 | 原则一 / 环境闸 |
| 硬排除 = 0 | 任一排除触发即剔除 | doc04 / 阶段4 |
| 盈亏比 ≥ 2:1 | `min_risk_reward=2.0` | ⑩ 测算（原则四 B1 出手门槛）【新增】 |
| 时间 < 14:30 + 买入窗口 | T-01 + 时段表 | 本文 A |
| 持仓 < 3 | `max_holdings=3` | D-02 |

> **盈亏比 R:R**：(止盈目标−入场价)/(入场价−止损价) ≥ 2。由 ⑩ 测算员用 D-05 的止盈位与止损位计算，达不到 2:1 直接不出手。

## 待你拍板

**Fork-A「排除≤1条」怎么处理**（与"任一排除触发直接剔除"冲突）
- **A1（推荐）**：**硬排除必须 = 0**；把"≤1条"重新理解为**软警示/信息缺口 ≤1 项**可容忍（如单个非关键数据缺口）。保持硬纪律不破。
- **A2**：字面允许命中 ≤1 条硬排除仍可买。直接违背"任一触发直接剔除"，等于给踩雷开口子，不推荐。

**Fork-B 早盘 09:30-10:00 是否允许买入**
- **B1（推荐）**：**默认不买**，仅观察/关注（量比>1.5）。买入集中在 10:00-11:30 与 13:00-14:30，避开开盘高波动博弈。
- **B2**：早盘允许买入（信号强 + 量比>1.5）。更灵活，但承担开盘剧烈波动风险。
