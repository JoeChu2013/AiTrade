## D-01 三档分级止损　【已建·强化】
组合层面的滚动浮亏，分档强制动作。进入区间即触发，恶化到 hard 线升级处置。

| 档 | 触发区间 | 动作 | 越过 hard 线 |
|---|---|---|---|
| 单日 | 整体浮亏 **-3% ~ -5%** | **整体减仓一半**（总仓位×50%） | <-5% → 当日整体清仓 |
| 单周 | 累计浮亏 **-5% ~ -8%** | **大幅降仓**（总仓位降至 **≤30%**，见 Fork-A） | <-8% → 清仓 |
| 单月 | 累计浮亏 **-8% ~ -12%** | **全部清仓 + 暂停交易复盘 5 个交易日** | <-12% → 延长暂停 |

- 现状代码用 `threshold_pct/hard_pct`，动作文案需按上表重写；"大幅降仓"需量化为目标仓位。
- **止损平仓不受 D-08 次数限制**（安全例外，下同）。

## D-02 持仓数量上限　【已建】
同时持仓 **最多 3 只**；满仓时禁止开新仓（杜绝过度分散）。`position.max_holdings=3`。

## D-03 单一仓位上限　【已建·强化】
单票占总资金不超过预设上限，按环境分级：S 40% / A 30% / B 20% / C 10% / D 0%（见 doc03）。
**【强化】**：`vet_trade` 需真正按环境 `max_single_position_pct` 封顶（当前用全局 40%）。

## D-04 浮亏不加仓　【已建】
个股出现**日内浮亏**时，绝不补仓摊薄成本。`position.no_add_on_intraday_loss=true`，对应 P-08。

## D-05 止盈分档兑现　【新增】
- **第一止盈位 `tp1 = +10%`** → **减半仓（-50%）**锁定利润。
- **剩余仓位"看趋势持有"** = 移动止盈：自持有期最高点**回撤 ≥ 6%** → 了结剩余（见 Fork-B）。
- **【新增参数】** `take_profit.tier1_pct=10`、`tier1_reduce_pct=50`、`trailing_drawdown_pct=6`。
- 与原则六不冲突：止损仍刚性，止盈改为"先落袋一半 + 移动止盈吃趋势"。

## D-06 不追突发暴涨 / 连续拉升　【新增】
**执行层过滤**（不是排除规则）：标的本身可研究，但出现暴涨形态时**当日禁止开新仓**。
触发任一即过滤：
- 近 **3 日累计涨幅 ≥ +20%**；或
- **单日涨幅 ≥ +9%**（近涨停）；或
- **连续涨停 ≥ 2 板**。
- **【新增参数】** `chase_filter.max_3d_gain_pct=20`、`max_1d_gain_pct=9`、`max_consecutive_limit_ups=1`(即≥2板过滤)。
- **承接 Fork-2=A**：追高/连板从"硬排除"降级到此处"执行层不开仓"。

## D-07 不频繁短线反复交易　【新增】
- 同一标的**卖出后冷却 ≥ 3 个交易日**才可再买（防来回打脸）。
- 同一标的 **20 日内完整买卖往返 ≤ 2 次**。
- **【新增参数】** `frequency.same_stock_cooldown_days=3`、`max_roundtrips_20d=2`。
- 目的：降手续费与出错概率。

## D-08 单日交易次数上限　【新增】
- 每日**开新仓 ≤ 3 笔**；每日**总交易（开+平）≤ 5 笔**。
- 触限后当日仅接受**硬止损强制平仓**（安全例外，不计入上限）。
- **【新增参数】** `frequency.max_new_trades_per_day=3`、`max_total_trades_per_day=5`、`stop_loss_exempt_from_limits=true`。
- 目的：避免频繁操作引发情绪化交易。

## 待你拍板

**Fork-A 单周"大幅降仓"量化**
- **A1（推荐）**：总仓位降至 **≤30%**（对齐 B 级仓位上限，口径统一）。
- **A2**：当前仓位**减 2/3**（相对值，与起始仓位挂钩）。更激进或更温和取决于初始仓位，口径不统一。

**Fork-B D-05 剩余仓位"看趋势持有"的了结方式**
- **B1（推荐）**：**移动止盈**——自最高点回撤 ≥ 6% 了结。能吃满趋势，回撤可控。
- **B2**：**第二止盈位**固定（如 +20% 再减半，+30% 清）。简单可预期，但趋势走强时容易过早下车。
