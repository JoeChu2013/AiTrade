# 详细设计 09 · 14 条永久禁止行为 + 排除规则分级

> 把风控、纪律固化在 AI 指令内：**任一禁令触发 → 本次分析直接作废重算**，不存在人为放宽/侥幸空间。
> 实现：每条要么架构天然保证，要么映射到会拦截的规则，要么运行时硬断言 `require()`。`ProhibitionError` = 硬失败。

## A. 排除规则分级（按你的新口径，更新 doc04）

| 命中硬排除条数 | 评级 | 可否开新仓 |
|---|---|---|
| 0 | 正常 | 可（仍需过买入条件闸） |
| 1 | 合格但有瑕疵 | 可（买入条件"排除≤1"放行，置信度扣分） |
| **≥2** | **只可观察（最低评级）** | **否**，保留在观察池、不剔出研究范围 |

- 这把"任一触发直接剔除"改为"**计数分级**"：≥2 条才降到只可观察。
- **⚠️ 安全红线例外（Fork-A 需确认）**：ST/*ST、退市风险、停牌、立案调查 这类**单条即致命**，建议**仍为绝对剔除（1 条即不可交易）**，不参与"容忍 1 条"。其余 8 条走计数分级。

## C.「作废重算」机制
```
run_with_enforcement(run_fn, max_retries=2):
    try 跑一次分析
    except ProhibitionError as e:
        作废本次结果 → 记录违规 P-id → 重算（带纠正提示）
        超过 max_retries 仍违规 → 升级人工裁决（不静默放行）
```
- 适用粒度：单只标的的一次完整分析（WF1 一轮）。
- 重算前注入"上次因 P-xx 作废"的纠正上下文，避免同样错误。
- **绝不 catch 后静默继续**：要么重算成功，要么升级人工。

## D. 难点：P-08 / P-13 / P-03 的强约束
LLM 仍可能"嘴硬"编数据或只贴原始数据。除架构强制外，加**确定性事后校验器**兜底：
- **P-13 未校准数据源**：关键财务/行情数字须能溯源到 dataflows 白名单数据源；无来源或来源不在白名单 → 判违规重算。
- **P-08 仅抛原始数据**：report 必须含"结论段 + 数值依据"，仅有原始表格/数据无加工结论 → 重算。
- **P-03 主观臆测填充**：缺失字段必须进 `info_gaps`，不得在该字段上编出具体数值/结论。
